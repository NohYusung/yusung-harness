요구사항을 기반으로 전체적인 구현 계획을 세우는 스킬이다.

# 작업 에이전트 목록

| 에이전트명  | 역할                                       |
| ----------- | ------------------------------------------ |
| coder       | 기존 코드 베이스 탐색 작업                 |
| designer    | 디자인 관련 작업(와이어프레임·에셋·디자인) |
| doc-curator | mcp서버 통한 문서 작업                     |
| researcher  | 리서치 작업                                |

## 전체 작업에 대한 Plan을 작성한다.

- 먼저 모든 작업 단위를 포함한 Plan을 작성한다.

## plan은 단계별로 task별로 scope를 나눠서 별도 문서 생성

- task별 기획 문서를 작성한다.
  - 태스크별 기획은 반드시 **\*체크리스트**형식의 작업 절차별 진행도가 포함되어야 한다.
    > **예시)**
    >
    > - [x] NestJs 모듈 등록
    > - [x] 공지사항 list 매서드 작업
    > - [ ] 공지사항 create 매서드 비관적 lock 작업
