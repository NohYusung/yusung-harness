# 매 코딩을 진행학기 전에 Conventions 문서를 참조

<HARD-GATE>

</HARD-GATE>

## 호출할 에이전트 목록

| 에이전트명 | 하는일                             |
| ---------- | ---------------------------------- |
| coder      | 코드 검색, 코드 작성, 코드 수정    |
| tester     | 단위별 코드 컴파일, 디버깅, 테스트 |

## Test Driven Development

> tester 에이전트가 테스트를 진행할 수 있게, 테스트 코드를 반드시 작성한다.
