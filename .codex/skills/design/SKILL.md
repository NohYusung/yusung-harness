## 호출할 에이전트 목록

> | 에이전트명 | 하는일                                                                     |
> | ---------- | -------------------------------------------------------------------------- |
> | designer   | 와이어프레임, 로고, ux, ui, 에셋 등등 디자인에 관한 작업 진행              |
> | coder      | 코드 검색, 코드 작성, 코드 수정                                            |
> | tester     | 단위별 코드 컴파일, 디버깅, 테스트                                         |
> | researcher | 비슷한 컨셉의 사이트들의 디자인, 에셋, ux, ui 구조 탐색 후 레퍼런스로 사용 |

## 산출물

| 산출물 종류      | 구현 수준                                                                                                   |
| ---------------- | ----------------------------------------------------------------------------------------------------------- |
| 와이어프레임     | UX 설계위주. 유저의 journey기반 모든 클릭 기반 와이어 프레임, 클릭이나 입력등 상호작용이 가능한 형태의 html |
| UI 설계 디자인   | html 기반 화면 디자인                                                                                       |
| 로고 디자인 에셋 | 최소 5개의 로고 디자인 에셋을 정리                                                                          |
