Task sidecar → Loki 로그 전송

Promtail은 EC2 agent가 아니라 각 Task의 sidecar다. Grafana는 Loki를 조회하며, 로그 전송 방향과 명확히 구분한다.

운영 AZ A pickme Promtail→Loki Container구조화 로그 전송
운영 AZ A pudding Promtail→Loki Container구조화 로그 전송
운영 AZ C pickme Promtail→Loki Container구조화 로그 전송
운영 AZ C pudding Promtail→Loki Container구조화 로그 전송
개발 pickme Promtail→Loki Container구조화 로그 전송
개발 pudding Promtail→Loki Container구조화 로그 전송

미결정 항목: Loki 장기 보관용 S3는 승인된 결정이 아니므로 이 구조도와 연결 집합에서 제외했다. 운영과 개발 데이터 저장소 사이에도 연결이 없다.
